# Профессии·2030 — атлас востребованных профессий

Статическая версия сайта: 47 профессий, 181 вуз, 1558 программ, 174 специальности и 27 колледжей в 70 регионах России. Страницы профессий и специальностей, единая география восьми федеральных округов, опросники подбора по ЕГЭ и ОГЭ, сравнение профессий и вузов, объёмная 3D-карта России с вузами, поиск и печатный отчёт.

Собрана с нуля на чистых HTML, CSS и JavaScript — без сборщика, зависимостей и сервера. Данные лежат в `data-core.js` и трёх чанках вузов, все расчёты идут в браузере. Это PWA: сайт устанавливается на телефон и работает офлайн.

## Публичная версия

Основной адрес: **<https://comesee10.github.io/atlas-2030/>**

Сайт размещён на GitHub Pages из репозитория <https://github.com/comesee10/atlas-2030>: файлы раздаются как статика, без сборки и сервера. Хеш-маршруты работают: например, <https://comesee10.github.io/atlas-2030/#/professions/ml-engineer>, <https://comesee10.github.io/atlas-2030/#/regions> и <https://comesee10.github.io/atlas-2030/#/about>.

Резервная одностраничная копия: <https://html.cafe/xaa936a27> — тот же атлас, собранный в один файл `atlas-2030-standalone.html`.

Короткие ссылки на основной адрес: <https://clck.ru/3WhSB9> и <https://tinyurl.com/22j4nek9>.

## Как посмотреть локально

Откройте `index.html` двойным щелчком — сайт работает и через `file://`, потому что навигация на хешах (`#/professions`).

Если нужен локальный сервер:

```powershell
# из папки atlas-2030
python -m http.server 8777
# или любой другой статический сервер
```

Затем откройте `http://localhost:8777/`.

## Как опубликовать

### GitHub Pages (основной способ)

Сайт раздаётся из ветки `main` репозитория `comesee10/atlas-2030`, каталог `/`. Сборка не нужна: в репозиторий кладутся готовые файлы.

Обновление после правок:

```powershell
# из папки atlas-2030
powershell -ExecutionPolicy Bypass -File .\publish-github.ps1
```

Скрипт отправляет `index.html`, `styles.css`, `app.js`, `data-core.js`, чанки `data-universities-1…3.js`, `catalog-expansion.js`, `sw.js`, `manifest.webmanifest`, `offline.html`, иконки, шрифты, `favicon.svg`, `robots.txt`, `sitemap.xml` и `README.md` через GitHub API. Git в системе не требуется. После отправки Pages пересобирает сайт за 1–2 минуты.

После правок CSS или JavaScript обновите параметр `?v=` у подключённых файлов в `index.html`, иначе браузер может показать старую версию из кеша.

### Netlify (альтернатива)

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите **всю папку** `atlas-2030` в окно браузера.
3. Получите адрес вида `https://random-name-123.netlify.app`.

Правила перезаписи не требуются: роутинг на `#`. Так же подойдут Cloudflare Pages или Vercel.

### После публикации

- В `sitemap.xml` указан текущий адрес; при переезде на свой домен замените `loc`.
- Проверьте прямые ссылки с хешем, например `/#/professions/ml-engineer`.
- При желании подключите свой домен в настройках репозитория (раздел Pages).

## PWA и офлайн

Сайт устанавливается на телефон и компьютер как приложение:

- `manifest.webmanifest` — имя, цвета, `standalone`, PNG-иконки 192/512 и maskable, ярлыки «Бюджетные места» и «Опросник».
- `sw.js` — при установке кеширует всю оболочку (HTML, CSS, JS, шрифты, иконки), навигацию отдаёт из сети с откатом на кеш и `offline.html`, статику — по стратегии stale-while-revalidate.
- `offline.html` — заглушка для страниц, которые ещё не открывались.
- Регистрация service worker выполняется только в защищённом контексте: `https` или `localhost`.

Шрифты **Onest** (интерфейс и текст) и **Lora** (заголовки) размещены в `fonts/` как woff2 с кириллицей и латиницей. Внешних запросов к Google Fonts нет, поэтому шрифты работают офлайн и не зависят от сторонних сервисов.

## Как обновить данные

1. Отредактируйте `atlas-data.json` (структура: `professions`, `universities`, `colleges`, `collegeDetails`, `details`, `methodology`).
2. Пересоберите `data-core.js` и три чанка `data-universities-1…3.js`: `data-core.js` начинается с `window.ATLAS=`, чанки добавляют вузы через `window.ATLAS.universities.push.apply(...)`. Файлы должны быть в UTF-8 без BOM.
3. Пересоберите одностраничную версию: `powershell -ExecutionPolicy Bypass -File .\build-standalone.ps1`. Сборщик встраивает CSS, JS, шрифты и картинки в один HTML.
4. Проверьте `#/professions`, `#/universities`, `#/admission`, `#/calendar`, `#/favorites`, `#/compare` и одну страницу каждого типа.

Быстрая проверка JSON в PowerShell:

```powershell
$j = Get-Content .\atlas-data.json -Raw -Encoding UTF8 | ConvertFrom-Json
$j.professions.Count; $j.universities.Count; $j.colleges.Count
```

## Отличия от исходной версии

- Поиск по всему атласу (кнопка в шапке или `Ctrl/⌘ + K`, `/`).
- Фильтры и сортировка каталога, состояние в URL.
- Сравнение до трёх профессий и двух вузов; на мобильных — карточками, без горизонтальной прокрутки.
- Панель «Мой выбор» в шапке: сохранённые ответы опросника, список сравнения и сквозной фильтр каталога (сфера + предметы ЕГЭ) с кнопкой сброса; счётчик на кнопке показывает число сохранённых пунктов.
- Опросник с разбором альтернативных наборов ЕГЭ (`Инф / Физ`), статусами «Бюджет вероятен / Пограничная зона / Платное обучение» и ссылкой на результат.
- Опросник после 9 класса: два предмета ОГЭ по выбору (русский и математика — обязательные), сфера и средний балл аттестата; на выходе — специальности колледжей со статусами «Аттестат проходит / Пограничная зона / Нужен балл выше».
- Печатная версия отчёта (кнопка «Печать / PDF»). Страница профессии печатается на A4 целиком: паспорт, радар и таблицы с читаемым кеглем, без скрытых анимациями блоков.
- Мобильное меню, адаптив до 360 px, `prefers-reduced-motion`.
- Доступность: skip-link, `aria-current`, фокус-ловушки в модалках, подписи полей.
- SEO: `robots.txt`, `sitemap.xml`, favicon, Open Graph, осмысленные `title` на каждой странице.
- Оглавление с подсветкой раздела и «паспорт» профессии, закреплённый при прокрутке.
- Раздел «Специальности»: 174 специальности, сгруппированные по коду и названию, со ссылками на вузы.
- Раздел «Регионы»: 8 федеральных округов и 70 субъектов РФ; вузы сгруппированы по округам и регионам, фильтры сохраняются в адресе.
- Страница «О проекте»: преимущества, честное сравнение и ограничения данных.
- Анимации: aurora-фон главной, shimmer заголовков, счётчики статистики, stagger-появление карточек, пульс городов, индикатор прокрутки и кнопка «наверх» с кольцом прогресса — всё отключается при `prefers-reduced-motion`.
- 3D и микроанимации: свет под курсором и параллакс слоёв в hero, интерактивное созвездие специальностей (3D-глобус с сеткой, орбитами и спутниками, импульсы по связям, редкие кометы и реакция на курсор), вращающиеся wireframe-куб, октаэдр и тор в том же слое, наклон карточек с мягким бликом, объёмная лента специальностей, вращающийся куб на странице 404, кнопка «Мне повезёт» со случайной профессией, акцентная полоса при наведении на строку каталога и плавная смена списка при фильтрации. На сенсорных экранах наклон и параллакс отключаются.
- Фон карточки «Порядок работы»: едва заметная фотография города под градиентной маской. Изображение скачано с Wikimedia Commons, конвертировано в WebP и размещено в репозитории; в standalone-версии встраивается как data URI. Автор указан в подвале сайта; при недоступности остаётся градиентный фон.
- Динамическая таблица «Где учиться» на страницах профессий: топ-12 программ по минимальному баллу, на мобильных превращается в карточки.
- Раздел «Бюджетные места»: KPI по округам, сортировка, фильтр и история проходных баллов за три года.
- Объёмная 3D-карта России в разделе «Карта»: силуэт страны в равновеликой конической проекции Альберса, экструзия объёма, координатная сетка и светящиеся метки городов с вузами. Рисуется на canvas без внешних тайлов и картографических библиотек, работает офлайн. Поворот — перетаскиванием, масштаб — колесом или кнопками, фильтр по федеральным округам, нажатие на метку открывает город в каталоге вузов.
- Граф «профессия → специальность → вуз», тепловая карта «округ × сфера» и bubble-график «балл × рост × масштаб» — на canvas и SVG, без зависимостей. Тепловая карта фильтруется по округу и сфере и плавно пересчитывает шкалу, bubble-график обновляется вместе с каталогом и поддерживает перебор точек стрелками.
- Страница профессии читается как история: закреплённое содержание с активным разделом и полосой прогресса, мягкое появление секций при прокрутке.
- Простая навигация: в шапке четыре раздела и меню «Ещё», на телефоне — нижняя панель с подписями; режимы «Я ученик» и «Я учитель или родитель» меняют подачу главной; поиск понимает обычные фразы («после 9 класса», «биология», «Москва бюджет»); возврат из профессии восстанавливает фильтры и позицию списка; термины объясняются по нажатию.
- Новые графики: график «спрос по сферам» на главной (47 профессий на шкале индекса, размер точки — число программ обучения, ромб — среднее по сфере, крайние значения подписаны), радар по шести навыкам с самопроверкой «подходит ли мне» на странице профессии, печатная подборка избранного для урока и родителя.
- Отдельная страница «Учителю и родителю»: сценарий занятия на 25–30 минут, шесть шагов, восемь вопросов для обсуждения, памятка для родителей и печать.
- Shared-element переход: карточка профессии превращается в заголовок страницы через View Transitions API, где браузер это поддерживает; при `prefers-reduced-motion` и в старых браузерах остаётся обычная смена раздела.
- Анимации блоков построены на CSS scroll-driven (`animation-timeline: view()`) там, где браузер это умеет, и на IntersectionObserver — где нет.
- Скелетоны загрузки: стартовая разметка в `index.html` и мерцающая подложка фотографии; магнитные кнопки слегка смещаются к курсору на устройствах с точным указателем.
- Светлая и тёмная темы с сохранением выбора; тема применяется сразу при переключении, переход между разделами анимируется. В светлой теме нет тёмных и серых подложек: фильтры, карточки, блоки урока, радар, нижняя панель навигации и дорожка индекса оформлены в светлых оттенках. Скролл горизонтальных блоков (график, таблицы, тепловая карта) стилизован под тему: светлый трек с бирюзовым бегунком.
- Анимации: проявление страницы при переходе, рост столбиков зарплаты по этапам карьеры, параллакс фотографии сферы, «камера влетает в город» на 3D-карте. Всё уважает `prefers-reduced-motion`.
- Фотобанк сфер: карточки сфер на главной и в каталоге, баннер сферы на странице профессии, подпись с автором и лицензией.
- PWA: манифест, service worker, офлайн-кеш всей оболочки, установка на домашний экран и ярлыки на приём и опросник.
- Шрифты Onest и Lora размещены локально (woff2, латиница и кириллица) — без обращений к Google Fonts.

## Ограничения

- Проходные баллы — ориентир по кампаниям 2024–2025 гг., а не гарантия поступления.
- Данные не обновляются автоматически: это срез атласа, а не API вузов.
- Для работы нужен современный браузер (ES2017+, `IntersectionObserver`).
